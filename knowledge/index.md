# Soul Sever

Terminal Soulseek client. Nicotine+ 3.3.11 is the feature target. An empty username asks for a Soulseek name and password. A name that is not already registered creates a new Soulseek account, and the sign-in form says that in the title style. A saved username logs in, and the header shows that result.
